Make privacy claims more carefully.

The Zcash Privacy Claims Linter is a local command-line tool that flags potentially overconfident privacy claims in text and configuration files, giving people a starting point for human review.

Get started Explore the source code ↗
Its purpose is careful communication, not a verdict. A flagged phrase is a prompt to review context, not proof that a statement is false or that a system is insecure.
Why this project

Privacy language deserves scrutiny.

Words such as “completely anonymous” or “impossible to track” can imply stronger guarantees than the surrounding evidence supports. This tool helps reviewers find language worth examining without pretending that automated pattern matching can settle complex privacy questions.

How it works

A lightweight review workflow.

01 / SCAN

Check supported files

Scan documentation and supported text or configuration formats in a local directory.

02 / FLAG

Find strong claims

Identify language associated with absolute anonymity, concealment, metadata protection, identity protection, or tracking prevention.

03 / REVIEW

Keep a human in the loop

Review the surrounding context and decide whether the wording needs clarification or evidence.

Try it locally

Run the linter.

Python is required. These commands clone the public repository, create an isolated environment, and install the project locally. 

git clone https://github.com/arkumta/zcash-privacy-claims-linter.git
cd zcash-privacy-claims-linter

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

# Scan the repository and print findings
zcash-privacy-lint . --format text

# Produce machine-readable JSON
zcash-privacy-lint . --format json

# Run the test suite (install pytest if needed)
python -m pip install pytest
python -m pytest -v

The command-line tool also supports GitHub Actions output and an option to fail when findings are present. See the repository documentation for the latest details.

Responsible use

Useful signals, not automated truth.

Human review remains essential.

The linter uses pattern-based rules. It may miss risky wording, flag harmless wording, or misunderstand context. Its sentence handling is heuristic, not a full understanding of natural language. A finding is not a security audit, a guarantee about Zcash, or a determination that a claim is inaccurate.

Treat results as review prompts. Verify technical statements against appropriate evidence and explain the scope and limits of any privacy guarantees.
